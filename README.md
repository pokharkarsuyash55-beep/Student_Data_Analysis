# 🎓 Student Data Analysis

## 📌 Project Overview
This project analyzes student data using Python, MySQL, Excel, Power BI, and Tableau. Python was used for data cleaning and Exploratory Data Analysis (EDA), while MySQL was used to validate the analysis through SQL queries. Interactive dashboards were created in Power BI, Tableau, and Excel to visualize key student insights.

---

## 🚀 Objectives
- Clean and preprocess student data.
- Perform Exploratory Data Analysis (EDA).
- Validate analysis using MySQL queries.
- Build interactive dashboards.
- Generate insights into student demographics and performance.

---

## 🛠️ Tech Stack

- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **Database:** MySQL
- **Visualization:** Power BI, Tableau, Microsoft Excel
- **Environment:** Jupyter Notebook

---

## 📂 Project Workflow

### 1. Data Cleaning (Python)

- Summary statistics

- Attendance analysis

### 3. SQL Validation (MySQL)
- Student count
- Gender distribution

- Class-wise statistics
- Probability calculations
- Cross-checked dashboard metrics

### 4. Dashboard Development
Created interactive dashboards in:
- 📊 Power BI
